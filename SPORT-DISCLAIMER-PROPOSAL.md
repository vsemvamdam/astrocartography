## 1. Что ещё нашлось попутно (важнее самого дисклеймера)

### 1.1. Самопроверка показывается только для НХЛ

`js/sport-view.js:154` — честный вывод проекта подаётся по условию `${hk ? … : ''}`, где `hk` — только хоккей:

> «Проверка на прошлых сезонах НХЛ (2018/19–2026/27, 9 929 матчей): карта называла победителя в 60 %
> матчей, и он выигрывал в 47,9 % случаев — столько же, сколько обещали ставки (48,1 %). Фаворит по
> ставкам в тех же матчах выигрывал в 60,4 %. Метод ничего не добавляет к коэффициентам.»

Для футбола — АПЛ, Ла Лига, Лига 1, ЛЧ, ЛЕ, ЛК (основной объём) — **этой плашки нет вообще.**
При этом 36 %/34 %, на которые ссылается аудит, — именно футбольные данные. Самая сильная честность
проекта спрятана от большинства матчей.

### 1.2. «Ориентир счёта» — конкретный счёт матча

`js/sport-view.js:153` для футбола выводит в вердикте: `Ориентир счёта: Арсенал 2:1 Челси`.
Это не «перевес», а точный счёт — самое провокационное для ставки утверждение на странице, и оно
показывается **без** предупреждения в том же блоке. НХЛ такого не выводит.

### 1.3. Ничего про ответственное отношение к ставкам

Ни в одной форме: нет «18+», нет «не является гарантией», нет упоминания, что прогноз не для ставок —
кроме спрятанной строки в карточке. Для сервиса, публикующего коэффициенты букмекеров, это тонкое место.

## 2. Сильная сторона, которую надо сохранить

Проект **сам** проверил свой метод и публикует результат в открытом виде.
Проверено по первоисточникам (не пересказ):

**Ветка `football-db`, `SUMMARY.md`, версия расчёта `2c570365`:**
- Матчей в базе: **19 066** (ЛЧ 2044, ЛЕ 3540, Лига 1 4073, АПЛ 4294, Ла Лига 4314, ЛК 801)
- Сыграно, с коэффициентами и точным местом стадиона: **15 277**
- Карта назвала победителя — он выиграл: **36 % при 36 % по ставкам (+0,1 ± 0,9)** — 9 484 матча
- Явный перевес: **34 % при 34 % (+0 ± 2)** — 1 997 матчей
- Фаворит по ставкам выиграл: 55 % при 53 % (+1,3 ± 0,8) — для сравнения
- Матчей с прогнозом, записанным **до** матча (единственная честная выборка): **75**, угадано 32 % при 33 %

**Ветка `sport-research`, `results/README.md`** (5 видов спорта, ~90 тыс. игр):
- НХЛ: 47,9 % при 48,1 % (**−0,2 ± 1,3**), фаворит 60,4 %
- НБА: 46,4 % при 46,5 % (−0,1 ± 1,1); MLB: 48,5 % при 49,2 % (−0,7 ± 0,9)
- Теннис: 49,1 % при 49,3 % (−0,2 ± 0,5); NFL: 50,6 % при 50,1 % (+0,5 ± 2,3)

**Вывод, который подтверждают данные:** метод не предсказывает исход лучше коэффициентов.
Это редкая интеллектуальная честность. Задача — не спрятать её, а сделать видимой: конкуренты
обещают точность, а AstroSky единственный, кто честно измеряет себя и публикует результат.

**Оговорка про цифры:** в трёх местах лиги показывают +0,8…+3,1 п. п. (ЛК +3,1 ± 5,2; ЛЕ +2,2 ± 3,0;
АПЛ +0,8 ± 1,8), но все — **в пределах двух стандартных ошибок**, то есть статистически неотличимы
от нуля. Публиковать их как «карта работает на еврокубках» было бы ошибкой. Формулировка должна это
учитывать.

## 4. Что я НЕ предлагаю (важно для позиционирования)

- **Не** убирать коэффициенты букмекеров — без них нет сравнения и нет смысла честной проверки.
- **Не** отказываться от вкладки «Спорт» — честность сама по себе преимущество.
- **Не** писать «гарантируем точность», «проверенная методика заработка», «ставь по карте».
- **Не** добавлять партнёрские ссылки на букмекеров — это прямо противоречит правилу 2 проекта.
- **Не** публиковать «+3,1 п. п. на Лиге конференций» как успех: это в пределах ошибки (см. § 2).
