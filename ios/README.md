# AstroSky для iOS

Нативное приложение на SwiftUI. Расчёты делает тот же движок, что и сайт (`js/*.js`): он работает внутри приложения в JavaScriptCore, поэтому цифры совпадают с сайтом до секунды, а исправления в движке сразу попадают в обе версии.

## Что есть

- **Натал**: колесо (как на сайте, с раздвижкой значков внутри дома), расшифровка по вкладкам, планеты с достоинствами, дома с управителями, аспекты, стихии и кресты. Колесо открывается на весь экран: щипок — приблизить, двойной тап — приблизить или вернуть.
- **Прогноз**: соляр на любой год и город, со списком лучших городов; лунар по методу Константина Дарагана (дома Плацидуса) с переходом по лунарам и выбором места. Расшифровка: «Главное», «Важные точки», «Планеты в домах».
- **Пара**: синастрия (двойное колесо, планеты партнёра в ваших домах, аспекты между картами) и композит, с расшифровкой.
- **PDF**: колесо и вся расшифровка словами, без таблиц — кнопка «Поделиться» вверху экрана.
- **Профиль**: ваши данные, партнёр, сохранённые карты, настройки карты (система домов, узел, точки, астероиды, минорные аспекты).

## Как собрать на Mac

```sh
brew install xcodegen
cd ios
xcodegen
open AstroSky.xcodeproj
```

В Xcode: цель **AstroSky** → *Signing & Capabilities* → *Team* — выберите свой Apple ID, подключите iPhone и нажмите ▶. С бесплатным Apple ID приложение работает на телефоне 7 дней, потом его надо поставить заново; с платным аккаунтом разработчика — год.

На iPhone в первый раз: *Настройки → Основные → VPN и управление устройством* — доверить разработчику, а в *Настройки → Конфиденциальность → Режим разработчика* включить режим разработчика.

## Проверка

- `node ios/scripts/expected.js` — эталонные значения из движка сайта.
- Тесты `AstroSkyTests` сверяют с ними расчёты в JavaScriptCore: натальная карта, история часовых поясов (Осло 1950, Москва 1985, Нью-Йорк 1975), соляр, лунар, синастрия, астероиды, PDF.
- GitHub Actions (`.github/workflows/ios.yml`) собирает приложение на macOS, гоняет тесты в симуляторе и кладёт скриншоты экранов и PDF в ветку `ios-ci`.

## Файлы

| Файл | Что внутри |
|---|---|
| `project.yml` | описание проекта для XcodeGen |
| `AstroSky/Engine/AstroEngine.swift` | загрузка движка в JavaScriptCore, вызовы на отдельной очереди |
| `AstroSky/Engine/bridge.js` | JSON-API поверх движка сайта: карта, соляр, лунар, синастрия, композит, города |
| `AstroSky/Engine/prelude.js` | `window` и `atob` для движка вне браузера |
| `AstroSky/Model/` | модели данных, форматирование, состояние приложения |
| `AstroSky/UI/WheelView.swift` | колесо гороскопа на Canvas, перенос `renderWheel` из `natal-view.js` |
| `AstroSky/UI/ChartScreen.swift`, `Cards.swift` | экран карты, расшифровка, таблицы |
| `AstroSky/UI/PDFBuilder.swift` | PDF как на сайте |
