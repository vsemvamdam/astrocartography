# Футбольная база

База для проверки вкладки «Спорт»: по каждому матчу АПЛ, Ла Лиги, Лиги чемпионов, Лиги Европы и Лиги конференций здесь лежат время начала, стадион и место, для которого строится карта, коэффициенты букмекеров, прогноз карты и результат. Ветку обновляет GitHub Actions (`.github/workflows/sport-db.yml` в ветке `main`) после каждой копии данных ESPN. Руками ничего не править: изменения перезапишутся.

## Файлы

- `SUMMARY.md` — сводка: как часто выигрывает фаворит по ставкам и как часто угадывает карта.
- `football.csv` — таблица для Excel и Google Таблиц, одна строка на сыгранный матч (разделитель «;»).
- `matches/ГГГГ-ММ.json` — все матчи месяца (по времени начала в UTC), ключ — номер матча ESPN.
- `venues.json` — места стадионов по городу и стране (GeoNames).
- `index.json` — когда обновлено и сколько матчей.

## Поля матча

- `kickoff` — назначенное начало, UTC. По Фроули карта строится на стартовый свисток по расписанию.
- `venue` — стадион, город и страна, как их даёт ESPN. `place` — где строится карта: `src: "geonames"` — город стадиона по GeoNames; `src: "site"` — по списку городов сайта; `approx: true` — город не нашёлся, взят крупнейший город страны. Такие матчи при проверке лучше не учитывать.
- `odds` — коэффициенты:
  - `espn` — последние перед матчем, как их видел сайт (американские, `open` — открытие линии, `close` — последняя);
  - `b365` — предматчевые Bet365 на исход матча (дробные), ESPN хранит их и после матча;
  - `core` — закрытие линии другой букмекерской конторы, если нет первых двух;
  - `model` — шансы по модели (bloomberg) для старых матчей без коэффициентов.
- `fav` — фаворит: `side` (`home` — хозяева, `away` — гости), `src` — источник, `p` — вероятности хозяев, ничьей и гостей без маржи букмекера.
- `judge` — прогноз карты текущей версией расчёта (`v` — первые знаки SHA-1 файла `js/sport.js`): `winner` (`home`, `away` или `draw`), `strength`, `score` — сумма свидетельств фаворита и аутсайдера, `diff` — их разница, `goals` — ориентир счёта, `t` — свидетельства (`fav` или `dog`, вес, вид, текст), `asc` и `mc` карты. В `alt` — вердикт с орбом Луны 6° и 7° (доп. время, пенальти), если он другой.
- `pre` — прогноз, записанный до начала матча. После стартового свистка он больше не меняется. У матчей прошлых сезонов его нет: их прогноз посчитан задним числом.
- `result` — `home` и `away` — итоговый счёт, `so` — серия пенальти, `ft90` — счёт после 90 минут, `winner90` и `winner` — победитель за 90 минут и итоговый, `status` — статус ESPN (`STATUS_FULL_TIME`, `STATUS_FINAL_AET`, `STATUS_FINAL_PEN`).
- `status` — `pre` до матча, `in` во время, `post` после; `postponed`, `canceled` и т. п. для перенесённых и отменённых.

## Как добавить прошлые сезоны или пересчитать прогнозы

GitHub → Actions → Football base → Run workflow:

- `seasons` — например `2018-2025` (сезон 2018 — с июля 2018 по июнь 2019);
- `rejudge` — пересчитать прогнозы всей базы новой версией `js/sport.js` (поле `pre` при этом не меняется).
