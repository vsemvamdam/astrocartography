# Карта Фроули по видам спорта

Обновлено 2026-11-06 05:48 UTC.

Одна и та же карта по «Спортивной астрологии» Фроули (js/sport.js): фаворит по ставкам — I и X дома, аутсайдер — VII и IV; карта на назначенное начало в городе арены. В теннисе ESPN хранит фактическое начало матча, назначенного времени у большинства матчей нет.

«Угадано» — как часто побеждал тот, кого назвала карта (в футболе — за 90 минут). «Фаворит» — как часто в тех же играх побеждал фаворит по ставкам. «По ставкам» — сколько обещали коэффициенты для стороны карты. Разница «Угадано» − «По ставкам» и есть то, что карта добавляет к ставкам; «±» — две стандартные ошибки, ** — разница больше неё.
